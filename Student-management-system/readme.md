# Student Management System

A responsive front-end application for managing student records.

## Technologies
- HTML5
- CSS3
- JavaScript ES Modules
- Browser Local Storage

## Features
- Dashboard statistics
- Add student
- View student records
- Edit student details
- Delete student records
- Search by name or roll number
- Filter by course
- Save records in Local Storage
- Responsive layout

## How to Run
1. Open the project folder in Visual Studio Code.
2. Install or enable Live Server.
3. Open index.html using Live Server.
4. Add student details through the form.

## Storage
Student records are stored under the localStorage key `studentHubRecords`.

## Current Limitations
- No server-side database.
- No authentication system.
- Data is stored in the current browser profile.
