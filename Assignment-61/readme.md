# Student Management System

## Project Description
A responsive web application for managing student records using HTML, CSS and JavaScript.

## Features
- Add student records
- View all students
- Edit student information
- Delete student records
- Search by student name or roll number
- Filter students by course
- Dashboard statistics
- Persistent data using localStorage

## Technologies
- HTML5
- CSS3
- JavaScript ES Modules
- Browser Local Storage

## Installation and Usage
1. Clone or download this repository.
2. Open the project in Visual Studio Code.
3. Run index.html using Live Server.
4. Add and manage student records through the dashboard.

## Project Structure
- index.html: Application structure
- style.css: Responsive styling
- js/app.js: Main application logic
- js/utils.js: Reusable utility functions
- docs/: Project and assessment documentation
- assessment/: Final working challenge
- screenshots/: Application screenshots

## Testing
The project includes test cases for adding, editing, deleting, searching, filtering and persistent storage.

## Limitations
This is a front-end educational project. Data is stored locally in the browser and is not synchronized with a server or shared between users.
