## Student Management System

**Project Type:** Front-End Web Development

**Technologies:** HTML5, CSS3, JavaScript, Local Storage

Developed a responsive Student Management System to organize and manage student records. Implemented features such as adding, editing, deleting, searching and filtering student information, along with dashboard statistics and persistent browser storage.

**Key Learning:** DOM manipulation, JavaScript functions, CRUD operations, form validation, localStorage, responsive design and GitHub version control.
